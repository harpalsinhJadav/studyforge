JSI & New Architecture
🔖
AI Summary
JSI is a C++ layer enabling synchronous, direct communication between JS and native — eliminating the async JSON bridge bottleneck of old React Native.
Key concepts
JSI exposes a C++ HostObject that JS can call synchronously
No more JSON serialization overhead on every bridge call
Enables TurboModules and Fabric without the old bridge
